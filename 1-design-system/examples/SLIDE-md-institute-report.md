# slide_template.md — institute-report

**Tags:** tone = Conservative · use-case = Read
**Reference:** research institute / government-style report · **Use case:** long-form research and policy reports — multi-section documents read at a desk, not presented live

## Colors
| role | name | hex |
|---|---|---|
| Background | cool white | #FAFDFB |
| Secondary | deep emerald | #14532D |
| Accent | deep emerald green | #14532D |
| Ink | near-black green | #11231A |
| Muted / hairline | sage / line | #88A090 / #DAE8E0 |

- Deep emerald is dark enough for body-size accent text (section numbers, the highlighted table column, headline figures) and reads as a calm, institutional mark.
- One accent only; chart non-accent series stay neutral gray.

## Typography
- Heading: **Iowan Old Style / Georgia** (serif) · Body: **system-ui**. Built to be read, so denser text is fine.

## Layout
- 16:9 · **numbered parts with `section-divider` slides between them** · a message line under each title · one chart or table per content slide · a source / footnote line where data appears.

## Do / Don't
- Do: split the document into parts with dividers; lead every finding with an action title; cite the survey base; use a single emerald accent.
- Don't: present this live as-is (it's read-mode), use bright multi-color charts, or skip the sources.
