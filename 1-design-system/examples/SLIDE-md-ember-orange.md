# slide_template.md — ember-orange

**Tags:** tone = Stylish · use-case = Present / Hybrid
**Reference:** AI product studio / web agency · **Use case:** company overview, capabilities, pitch decks — warm and confident

## Colors
| role | name | hex |
|---|---|---|
| Background | warm white | #FFF8F2 |
| Secondary | warm near-black | #211913 |
| Accent | ember orange | #C2410C |
| Ink | warm near-black | #211913 |
| Muted / hairline | warm taupe / line | #9C8B7C / #EADDD0 |

- 60-30-10: warm white ground (60) · near-black ink (30) · ember orange (10).
- Body text uses ink on warm white (passes WCAG AA ≥ 4.5:1). Orange is for accents, big numbers, one chart series, and chips/badges only.

## Typography
- Heading: **Iowan Old Style / Palatino / Georgia** (serif) · Body: **system-ui / Helvetica Neue**
- Display 7–8cqi / 600 · H1 ~4cqi / 600 · Body ~1.9cqi / 400. Action titles (full-sentence conclusions).

## Layout
- 16:9 · generous margins · one chart/table per slide · fixed positions for logo (top-right), title, page number.

## Do / Don't
- Do: warm-white ground + a single ember-orange accent; large serif numbers; one idea per slide; charts = one orange series, the rest neutral gray.
- Don't: more than one bright color, neon orange for body text, decorative gradients or rainbow charts.
