# slide_template.md — northgate-report

**Tags:** tone = Conservative · use-case = Read / Hybrid
**Reference:** strategy consulting / government report · **Use case:** market studies, board reports, due-diligence decks — formal and dense

## Colors
| role | name | hex |
|---|---|---|
| Background | cool white | #F6F8FB |
| Secondary | navy | #1E3A5F |
| Accent | navy | #1E3A5F |
| Ink | near-black | #152234 |
| Muted / hairline | slate / line | #8893A6 / #DBE2EC |

- Navy is dark enough to use for body-size accent text (high contrast). Highlight just one table column or one chart series.

## Typography
- Heading: **Iowan Old Style / Georgia** (serif) · Body: **system-ui**. Dense but legible.

## Layout
- 16:9 · a message line (lead sentence) under each title · charts/tables are central · a source / footnote line at the bottom · section dividers between parts.

## Do / Don't
- Do: navy structure + a restrained accent; sophisticated tables (one highlighted column); action titles that state the finding; cite sources.
- Don't: bright multi-color charts, decorative imagery, more than one accent color.
