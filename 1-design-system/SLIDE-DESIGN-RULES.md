# SLIDE-DESIGN-RULES.md — the rulebook

> The thinking behind `slide_template.md`. Distilled from the canonical authorities (Duarte, Reynolds,
> Tufte, Robin Williams, Kawasaki, Alley, McKinsey/Minto; and Japanese presentation authorities Toyomane, Maeda, and the Tsutawaru-Design guide).
> Keep slides honest to these; the design system enforces the look, this enforces the craft.

## The one rule above all — who carries the words?
- **present** (you speak): the slide is visual support — 1 idea, ≥30pt, a sentence or a number, big visual.
- **document** (read alone): the page explains itself — full sentences, denser, smaller body, appendix.
- The hybrid that's too dense to present and too thin to read is the **"slideument"** — never ship it.

## Universal principles
1. **One idea per slide.**
2. **Action title** = a full sentence stating the point ("Q4 grew 41%"), not a label ("Revenue"). Reading titles in order should tell the story.
3. **3-second glance test** (billboard).
4. **Signal > noise** — delete gridlines, frames, 3-D, decoration, redundant labels.
5. **Show, don't tell** — image/chart/diagram beats bullets.
6. **Big, legible type** (≥30pt projected); sans; ≤2 fonts.
7. **CRAP** — Contrast, Repetition, Alignment, Proximity.
8. **Limit color (≤3) and effects.** 60-30-10. One accent.
9. **Charts:** one chart = one idea; declarative title; direct labels; highlight one series; avoid pie/donut; zero baseline.
10. **Logic before design** — message-first, ghost-deck the titles, then design.

## Tone (orthogonal to mode)
- **Conservative** — muted, neutral sans, strict grid, data-forward (consulting/finance/gov).
- **Balanced** — clean brand color + whitespace, still credible (most B2B).
- **Stylish** — big type, full-bleed imagery, editorial; design-forward (keynote/pitch/brand).

## Diagrams that look professional (not amateur)
- Strict alignment + **equal spacing** (distribute), identical node shapes, **one flow direction**, clean arrows, ≤5 nodes (split if more), functional color only (1 accent + grays).
- Prefer real, legible diagrams: process flow, decision flowchart, swimlane, funnel, pyramid, venn, sequence diagram, timeline/gantt, 2×2 matrix, org tree. Avoid busy radial/spoke/cycle art.

## Anti-patterns → fix
- Wall of text → move detail to notes; ≤3 points; sentence headline + visual.
- Topic title → action title.
- Tiny fonts → ≥24pt body (≥30pt projected); if it won't fit, it's too much — split.
- 3-D / chartjunk / rainbow → flat, high data-ink, one accent.
- Pie with many slices → sorted bar / single stacked bar.
- Inconsistent fonts/colors → set once in the design system.
- Misalignment → align everything to the grid.
- Low contrast → ≥4.5:1 (≥3:1 large).
- Color-only meaning → add label/icon/pattern.

## Pre-flight checklist (done = passes all)
- ☐ One Big Idea; conclusion first; titles-only tells the story.
- ☐ Every slide: action title, one message, sources cited, no wall of text.
- ☐ Theme fonts/colors only; ≤2 fonts; consistent title position; grid-aligned; one focal point.
- ☐ Charts flat/labeled/zero-baseline; images meaningful; subtle, consistent animation.
- ☐ Contrast ≥4.5:1; body ≥24pt; alt text; not color-alone.
- ☐ Each slide readable in ~30s; the audience can repeat the core message.
