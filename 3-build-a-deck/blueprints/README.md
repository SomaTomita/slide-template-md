# Deck blueprints

Four ready-made storylines — each is a `SLIDE-DECK-*.md` with the slide-by-slide
structure and pattern assignments already done. Fill in the `{{...}}` content,
attach your `slide_template.md`, and hand it to your AI (see `../BUILD-A-DECK.md`).

| Blueprint | Use it for | Looks like (see `examples.html`) |
|---|---|---|
| [sales-proposal.md](sales-proposal.md) | Proposing to a prospect or client | A consulting report — Northgate Advisory |
| [company-pitch.md](company-pitch.md) | A company/product pitch or intro call | A studio pitch — Ember |
| [quarterly-report.md](quarterly-report.md) | A recurring numbers update (quarterly, IR, board) | By the numbers — Hinode Health |
| [research-report.md](research-report.md) | A long-form research or policy report | A long-form report — The Digital Economy Institute |

None of these are fixed — add, remove, or reorder slides to fit what you actually
need to say. The pattern assignments are a starting skeleton, not a rulebook.
